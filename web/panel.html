Panel del organizador

Inicio de sesión con JWT y CRUD de organizadores, eventos, tipos de boleta y órdenes sobre la API REST del MVP. Cada petición y su respuesta quedan a la vista en «Peticiones a la API».

Iniciar sesión

POST /sesiones · el servidor verifica la clave (bcrypt) y entrega un JWT que vence en 8 horas.

Cuenta de demostración (la crea npm run demo): demo@apparchar.co · Apparchar2026.

Crear cuenta de organizador

POST /organizadores · la clave se guarda como hash bcrypt, nunca en claro.

Sesión iniciada:

Ver el token JWT que entregó el servidor

Viaja en cada petición protegida como Authorization: Bearer …. Está firmado con HS256 y la clave secreta del servidor: si alguien lo altera, la firma deja de coincidir y el servidor responde 401.
