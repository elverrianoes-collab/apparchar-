(360 px) y escritorio (1280 px), con anotaciones numeradas. Se redibujaron en la
Entrega 2 para que correspondan a lo que hoy hace el prototipo de [`web/`](../../web/).

| Archivo | Pantalla |
|---|---|
| [`01-cartelera.png`](01-cartelera.png) | Cartelera (`index.html`): pantalla principal, filtros y los tres estados |
| [`02-detalle-y-compra.png`](02-detalle-y-compra.png) | Detalle del evento y compra (`detalle.html`) |
| [`03-publicar-evento.png`](03-publicar-evento.png) | Publicar evento (`publicar.html`) |
| [`04-validar-en-puerta.png`](04-validar-en-puerta.png) | Validar boletas en la puerta (`puerta.html`) |

Si el equipo quiere conservar los wireframes originales de la Entrega 1 para
comparar cómo cambió cada pantalla, se agregan aquí con el prefijo `entrega-1-`.
